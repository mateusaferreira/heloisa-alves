# Heloísa Alves Imóveis

Site responsivo com casas e apartamentos em Londrina. Página principal com busca e filtros. Maison Giverny em /imoveis/maison-giverny/ e demais anúncios em páginas próprias.

HTML, CSS e JavaScript sem etapa de build. Publique o diretório raiz como site estático.

Contatos e convite do grupo em `site-config.js`. As mensagens de WhatsApp identificam o imóvel, seu valor e a página de origem.

Recomendações deslizantes com controles no desktop. Propostas enviadas pelo WhatsApp. Sitemap e dados estruturados nas páginas. Identidade visual fornecida pelo responsável pelo site.
